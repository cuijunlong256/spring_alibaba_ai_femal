# 明星画像深度匹配技能

## 技能描述
根据用户对对象的描述（年龄、星座、国籍、性格偏好等），从明星知识库中检索并打分排序，返回最匹配的明星推荐。

## 适用场景
- 用户要求推荐对象、介绍男女朋友
- 用户描述了对对象的具体要求（如"30-40岁狮子座"）
- 用户想换一批推荐（"除了她们还有谁"）
- 用户想在已推荐的人中筛选（"她们谁喜欢读书"）

## 执行方式
调用 `celebrityMatchTool` 工具，传入以下参数：
- `query`：用户的原始描述文本
- `gender`：目标性别，female（推荐女性）或 male（推荐男性）
- `sessionId`：当前会话ID，用于记录和排除已推荐的明星

## 输出说明
工具返回匹配度最高的前5位明星，每位包含：
- 姓名、年龄、星座、国籍
- 性格标签、兴趣爱好
- 匹配度百分比（越高越匹配）

## 注意事项
1. 本技能仅用于推荐，不处理用户的情感倾诉
2. 如果用户只是闲聊，不要调用本技能
3. 推荐结果是真实的明星资料，非虚构
